# Antigravity 汉化一键工具（单文件版）

把 Antigravity（反重力）汉化包做成**一个 .bat 文件**：双击 → 选菜单 → 自动完成，不用再解压一整个文件夹。

## 用法

1. 下载 `反重力汉化一键工具.bat`（约 460 KB）。
2. 双击运行，按菜单选：
   - `1` 安装简体中文
   - `2` 安装繁体中文
   - `3` 卸载还原官方英文
3. 安装时再选左上角品牌显示方式（保持英文 / 隐藏 / 汉化为「反重力」），然后等它跑完。

环境要求：Windows，已安装 Antigravity。运行时需要 Node.js，**或者** Antigravity 装在常见路径下（脚本会借用 Antigravity 自己的 exe 作为 JS 运行时，二者有一个即可）。

## 它是怎么做到只有一个文件的

- 原汉化包约 70 MB，其中 69.8 MB 是一个 node.exe 运行时；真正的汉化载荷（引擎 + 字典）不到 1 MB。
- 本脚本把载荷压缩后内嵌在 .bat 里，运行时释放到临时目录执行，跑完自动清理。
- 运行时优先用系统 Node.js；没有 Node.js 时用 `ELECTRON_RUN_AS_NODE` 借 Antigravity 自身的 exe 执行引擎，效果相同。

## 说明

- 汉化引擎与字典来自 antigravity2-cn 汉化包，本仓库只是把它的安装方式改成单文件一键版。
- 安装前引擎会自动备份官方 `app.asar`（`app.asar.bak`），菜单 `3` 即靠它还原。
- Antigravity 客户端更新后汉化会被覆盖，重新双击运行一次即可。
- 自释放型 .bat 偶尔会被杀毒软件误报，介意的话可以对照原汉化包使用。
