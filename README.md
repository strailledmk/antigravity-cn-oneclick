# Antigravity 汉化一键工具（单文件版）

## 介绍

Antigravity 是 Google 推出的 AI 编程 IDE（俗称「反重力」），界面只有英文。现有的汉化方案要先下载一个约 70 MB 的文件夹，解压后再双击里面的安装 bat，步骤多、文件杂。

本工具把汉化做成了**一个 .bat 文件**（约 460 KB）：下载 → 双击 → 选菜单 → 完成。安装简体、安装繁体、卸载还原三合一，不用解压、不用翻文件夹。

它和原文件夹版用的是**同一套汉化引擎和同一份字典**，汉化效果完全相同，只是打包方式不同：原包 70 MB 里有 69.8 MB 是一个 node.exe 运行时，而真正的汉化载荷不到 1 MB——本工具就把这 1 MB 内嵌进 bat，运行时借用现成的 JS 引擎执行，所以文件能做到这么小。

## 使用方法

1. **下载**：在本仓库页面点开 `反重力汉化一键工具.bat`，点右上角的下载按钮（Download raw file）保存到电脑上。
2. **双击运行** `反重力汉化一键工具.bat`。
3. **选主菜单**：
   - `1` — 安装简体中文
   - `2` — 安装繁体中文
   - `3` — 卸载还原官方英文
   - `Q` — 退出
4. **选品牌样式**（仅安装时）：左上角的品牌名怎么显示——
   - `1` — 保持英文 Antigravity（推荐）
   - `2` — 隐藏品牌名
   - `3` — 汉化为「反重力」
5. 等待执行：脚本会自动关闭正在运行的 Antigravity、备份官方文件、注入汉化、清理临时文件。看到「[完成] 操作成功！」后重新打开 Antigravity，界面就是中文了。

**环境要求**：Windows 系统，已安装 Antigravity；另外需要有 Node.js，**或者** Antigravity 装在常见路径下（脚本会借用 Antigravity 自己的 exe 当运行时）。两者都没有时脚本会提示先装 Node.js；万一自动定位不到 Antigravity，按提示粘贴它的安装目录即可。

## 工作原理

- bat 内嵌了一段 Base64 编码的压缩载荷，内容是汉化引擎 `localization_engine.js`、补丁代码 `src/` 和简/繁两套字典 `dicts/`、`dicts_tw/`。
- 运行时载荷释放到临时目录 `%TEMP%\AgyCnTool`，执行完自动删除，不在电脑上留东西。
- JS 运行时按顺序找：系统 Node.js → Antigravity 自身的 exe（通过 `ELECTRON_RUN_AS_NODE` 以 Node 模式运行），并在正式执行前先做一次自检，自检不过会明确报错、不会乱改文件。
- 汉化引擎的原理是修改 Antigravity 安装目录下的 `resources\app.asar`，注入运行时翻译补丁（菜单、设置页、Agents 页、MCP 页等界面文字）。

## 卸载还原

双击 bat，菜单选 `3` 即可。原理是恢复安装时自动备份的官方文件 `app.asar.bak`。注意：如果备份被删掉，就无法这样还原，只能重装 Antigravity 恢复英文。

## 注意事项

- Antigravity 客户端更新后，汉化会被官方文件覆盖，重新双击运行一次本工具即可。
- 运行前不用手动关 Antigravity，脚本会自己关——但请先保存好正在编辑的内容。
- 自释放型的 .bat 偶尔会被杀毒软件误报，介意的话请使用原文件夹版汉化包。
- 本工具只改界面语言，不动账号、不动项目文件。

## 来源
